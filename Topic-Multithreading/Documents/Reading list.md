# C# Multi-threading Reading List

This curated reading list focuses on high-quality, concise resources for understanding multi-threading in C# with an emphasis on thread-based approaches (not Task-based) and robotic applications.

## Official Documentation

1. [Managed Threading Best Practices](https://learn.microsoft.com/en-us/dotnet/standard/threading/managed-threading-best-practices) - Microsoft's official guide on threading best practices including when to use which synchronization primitives.

2. [Overview of Synchronization Primitives](https://learn.microsoft.com/en-us/dotnet/standard/threading/overview-of-synchronization-primitives) - A comprehensive explanation of the built-in synchronization mechanisms in .NET.

3. [Synchronizing Data for Multithreading](https://learn.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/threading/thread-synchronization) - Explains different approaches to protect shared resources in multithreaded environments.

4. [Thread-Safe Collections](https://learn.microsoft.com/en-us/dotnet/standard/collections/thread-safe/) - Explores the thread-safe collection classes available in the System.Collections.Concurrent namespace.

## Thread Synchronization

1. [C# Threading and Multithreading: A Guide With Examples](https://www.pluralsight.com/guides/csharp-threading-and-multithreading) - A practical guide with real-world examples of threading implementations.

2. [Thread Synchronization using Lock in C#](https://www.c-sharpcorner.com/article/thread-synchronization-using-lock-in-C-Sharp/) - A detailed explanation of lock-based synchronization with practical examples.

3. [The lock statement - synchronize access to shared resources](https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/statements/lock) - Official documentation about the lock statement with code examples.

## Channels and Producer-Consumer Patterns

1. [An Introduction to System.Threading.Channels](https://www.stevejgordon.co.uk/an-introduction-to-system-threading-channels) - Excellent explanation of channels and their implementation for producer-consumer scenarios.

## Real-World Applications

1. [Real-world Examples Of Multithreading In .NET Applications](https://michaelscodingspot.com/real-world-examples-of-multithreading-in-net/) - Practical examples of multithreading in production applications.

2. [Thread Synchronization Overview](https://www.albahari.com/threading/part2.aspx) - An overview of thread synchronization with real-world performance considerations.

## Advanced Topics

1. [Interfacing With Multithreading Patterns](https://www.codeproject.com/Articles/5262235/Interfacing-With-Multithreading-Patterns) - Explores various multithreading patterns and their appropriate use cases.

## General Best Practices

1. [What Is Thread-Safety and How to Achieve It?](https://jenkov.com/tutorials/java-concurrency/thread-safety.html) - While Java-focused, the concepts apply well to C# and explain thread safety fundamentals.

2. [C# Multithreading](https://dotnettutorials.net/lesson/multithreading-in-csharp/) - A concise introduction to multithreading concepts and best practices.
